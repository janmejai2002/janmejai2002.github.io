## Image support (new)

The site had no image path at all. It now has one.

- `site/src/content.config.ts` uses the content-collections `image()` helper for
  `heroImage` and an optional `ogImage`. `heroAlt` is enforced by `superRefine`:
  a hero without alt text is a **build error**, not a lint warning. This is the
  same reasoning as the existing 70/160-character caps on `title`/`description`.
- `site/src/layouts/Post.astro` renders the hero with `<Image>` (widths 640/960/1280,
  explicit width/height, so nothing shifts) and derives a real 1200×630 PNG social
  card at build time with `getImage()`.
- `site/src/components/SEO.astro` now emits `og:image`, `twitter:image`, dimensions
  and alt, absolutised against `site`, with `/og-default.png` as the site-wide
  fallback. `summary_large_image` is no longer a promise the page cannot keep.
- `site/plugins/rehype-figure.mjs` wraps image-only paragraphs in `<figure>` and
  turns the markdown title into a `<figcaption>`. Paragraphs mixing an image with
  text are deliberately left alone. All three cases were verified against built HTML.
- `site/scripts/make-images.mjs` renders the SVG sources in `site/assets-src/` into
  `public/` (favicon.ico, apple-touch-icon, og-default) and `src/assets/` (article
  heroes). Re-run it after editing any SVG source; the outputs are committed.
- Favicon set added. `favicon.svg` is an open ensō, stroke-only so it reads on light
  and dark browser chrome.

**Gotcha worth keeping:** `favicon.ico` is written by hand in that script — a 22-byte
header wrapping a PNG payload — because `sharp` cannot emit ICO.

## New gotchas

- **The Bash tool is broken on this machine** (`cygheap read copy failed`). Everything
  in this session ran through PowerShell. Use it, or Git Bash via `& "C:\Program Files\Git\bin\bash.exe" -lc`.
- **`notebooklm-mcp` reports healthy in `claude mcp list` but exposes no tools to the
  session.** Do not waste time debugging it — the `nlm` CLI works and does the same job.
  Note `nlm query` needs the subcommand: `nlm query notebook <id> "..."`.
- **`nlm` auth expires often.** `nlm-relogin.sh` fixes it, but it force-kills Brave.
  Check whether Brave is running with open tabs before firing it.
- **A dense SVG must not be allowed to scale down to a phone.** `.diagram svg` has
  `min-width: 42rem` so it scrolls inside its box instead; at 320px an unconstrained
  700-unit viewBox renders 11px labels at 7px.
