# wAIbi-sabi — Gemini Spark Task 2: Master Article Writer Prompt (Fully Autonomous)

This document provides the complete, publication-grade **Gemini Spark Task 2 Prompt** for automatically drafting all three daily articles (Technical, Business, and Basics) directly from the SEO briefs generated by Task 1, requiring **zero manual intervention**.

---

## 1. Google Sheet Setup (`Drafts` Tab)

Ensure the tab **`Drafts`** in your Google Sheet [`wAIbi-sabi News`](https://docs.google.com/spreadsheets/d/1-UcD-C4My_Zp4aH3n-5dB3JQNtDN_MSAK6vTCPt8LY0/edit) has these 6 column headers in Row 1:

```
Date	Track	Title	DocUrl	Draft	Status
```

| Column | Header | Content Description |
|---|---|---|
| **A** | `Date` | Today's date (`YYYY-MM-DD`) |
| **B** | `Track` | `Technical`, `Business`, or `Basics` |
| **C** | `Title` | Article title (**strict cap: ≤ 70 characters**) |
| **D** | `DocUrl` | Optional Google Doc URL (leave blank if pasting markdown in Column E) |
| **E** | `Draft` | The complete, publication-ready markdown article body |
| **F** | `Status` | Set to `"Ready"` |

## 3. How the Autonomous Ingestion & Publishing Loop Executes

Once Gemini Spark finishes appending the 3 drafts at ~07:30 AM IST:

1. **Automated Ingestion (`sync-drafts.mjs`)**:
   GitHub Actions workflow `.github/workflows/sync-news.yml` runs automatically on schedule:
   - Fetches the `Drafts` tab from your Google Sheet.
   - Detects the 3 new rows with `Status = "Ready"`.
   - Parses the metadata, Executive TL;DR, and SVG artwork.
   - Creates 3 corresponding pages in Notion Article Production (`d39ea073...`) at `Draft Status: Draft Ready`.
   - Runs preflight assertions (`publish-article.mjs --check <id>`) to confirm all gates pass.

2. **Automated Publication (`publish-from-notion.yml`)**:
   - `publish-from-notion.yml` runs every 30 minutes.
   - For all unattended tracks (`Basics`, `Case Studies`, `Talks`), it commits straight to `main`, converts the SVG into dual WebP hero images via Sharp, runs `npm run build`, and deploys live in ~3 minutes.
   - For reviewed tracks (`Technical`, `Business`), it opens a Pull Request on `notion/approved-articles` (or deploys straight to `main` if added to `AUTO_TRACKS`).
   - `close-loop.mjs` verifies the live HTTP 200 URLs and marks the Notion rows `Published`!
